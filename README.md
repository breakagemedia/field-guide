# The Breakage Field Guide

Public copies of the guide that accompanies the Breakage channel, in two editions:

- `card.pdf`: the subscriber card, cover plus two pages
- `sources-edition.pdf`: the full guide with every citation and retrieval date

Both are built from Markdown by a script in the channel's private research repository and published here so the card's "the sources edition carries the citation" has a permanent link behind it. Version 1, sources checked 28 August 2026.

Breakage is journalism and education, not financial advice.
